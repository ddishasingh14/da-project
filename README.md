
# Student Performance Analysis

## Project Overview
A data analysis project using Python to
analyze student marks and attendance.

## Technologies Used
- Python
- NumPy
- Pandas
- Matplotlib

## Features
- Student dataset creation
- Data cleaning
- Missing value and duplicate checks
- Average marks calculation
- Highest and lowest scorer identification
- Attendance and marks correlation
- Performance classification
- Data visualization

## Analysis
The project calculates subject-wise averages,
student performance and attendance statistics.

It also creates bar charts and scatter plots
to visualize the dataset.

## How to Run
1. Install Python.
2. Install the libraries:

   pip install numpy pandas matplotlib

3. Run:

   python student_analysis_main.py

## Dataset
A sample dataset of 10 students is used
for demonstration.
